힐링브리즈 마케팅팀이 클라이언트별 **매체(광고)·오가닉 지표**를 한 화면에서 보는 내부 대시보드예요.

## 무엇을 보여 주나요

| 구분 | 지표 |
|---|---|
| 광고 | 소진액, 노출, 클릭, CTR, CPC, CPM, 매체 전환 |
| 광고 → 랜딩 | 랜딩 방문, 도착률, 방문당 비용 (메타 캠페인·소재) |
| 홈페이지 | 세션, 홈페이지 전환, 전환율, 유입 경로 (GA4) |
| 오가닉 | SNS 팔로워·조회수, 유튜브 업로드, 구글 검색 클릭·노출·평균 순위 |

<Callout title="아직 보여 주지 않는 것">
  DB, 상담, 예약, 내원, 매출, CPL, CPA, ROAS 는 병원 CRM(KOS) 데이터가 있어야 해서 아직 없어요.
  화면의 '전환'은 **매체나 GA4 가 센 전환**이지 실제 예약이 아니에요.
</Callout>

## 숫자가 오는 길

```
매체 API (네이버·메타·GA4·서치 콘솔·인스타그램·유튜브)
  → [동기화] 버튼 또는 npm run sync
  → DB
  → 화면
```

- 화면 상단의 **[동기화]** 를 누르면 최근 35일치를 다시 받아 덮어써요. 매체가 전환·비용을 며칠 늦게 고치기 때문이에요.
- 오늘은 아직 진행 중이라 **어제까지**만 받아요.
- 화면 위쪽의 "마지막 동기화" 시각이 숫자의 기준 시점이에요.

## 클라이언트

| 클라이언트 | 광고 | 그 밖 |
|---|---|---|
| GU강남 (지유의원 강남점) | 메타(해외), 네이버 검색광고 | GA4, 서치 콘솔, 캠페인 랜딩 GA4, 인스타그램, 유튜브 |
| GU일산 (지유의원 일산점) | 네이버 검색광고, 메타 | GA4, 서치 콘솔, 인스타그램, 유튜브 |
| 루호 (루호성형외과) | 메타 | GA4, 서치 콘솔, 인스타그램, 유튜브 |

## 이 문서 고치는 법

- 문서는 `content/docs/` 의 `.mdx` 파일이에요. 마크다운처럼 쓰면 돼요.
- 왼쪽 메뉴 순서는 `content/docs/meta.json` 의 `pages` 순서를 따라요. 새 페이지를 만들면 여기에도 이름을 넣어 주세요.
- **"현재 값"이라고 적힌 표는 코드에서 바로 읽어 와요.** 문턱값이나 전환 이벤트를 코드에서 바꾸면 문서도 저절로 바뀌니, 그 표는 손으로 고치지 않아도 돼요.
- `npm run dev` 로 띄우고 `localhost:3000/docs` 에서 확인해요.
