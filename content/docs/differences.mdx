## 광고 관리자와 다를 때

1. **마지막 동기화 시각**을 확인해요. 동기화 뒤에 매체가 고친 값은 다음 동기화 때 들어와요.
2. **날짜 범위**를 맞춰요. 대시보드는 어제까지예요. 오늘을 포함하면 달라요 ([기간과 비교](/docs/periods)).
3. **메타 클릭**은 링크 클릭이에요. 광고 관리자의 '클릭(전체)'과 비교하면 대시보드가 적어요.
4. **메타 계정 시간대**: 힐링브리즈 계정은 LA 시간대라 서울 기준 날짜와 하루씩 밀려 보일 수 있어요.
5. **클라이언트 나누기**: 캠페인 이름에 "일산"·"강남"이 있으면 계정과 상관없이 그 지점으로 가요 ([데이터 출처](/docs/sources#메타)).

## 전환이 0일 때

- 메타 광고가 **LINE · 카카오 · 홈페이지**로 보내면 메타가 전환을 알 수 없어서 0이에요. 메시지(WhatsApp·메신저·인스타 DM)와 인스턴트 양식만 세요.
- 홈페이지 전환은 [GA4 홈페이지 전환](/docs/sources#ga4-홈페이지-전환) 의 이벤트를 봐요.

## CTR·CPC 합계가 캠페인 평균과 다를 때

비율은 원본 값을 먼저 더한 뒤 나눠요. 노출이 많은 캠페인의 비율에 더 가까워지는 게 맞아요 ([지표 정의](/docs/metrics)).

## 국가별 합계가 타겟 국가와 다를 때

국가는 광고를 본 사람이 있던 나라예요. 타겟 밖 나라에서 본 노출이 조금씩 섞여요.

## 화면에 숫자가 안 보일 때

- "사내 네트워크에서만 볼 수 있어요" → 사내 네트워크(허용된 IP)에서 열어 주세요.
- `—` → 분모가 0이에요 (노출 0, 클릭 0, 소진액 0 등).
- 매달 1일의 '이번 달' → 아직 데이터가 없어요. 지난달을 보세요.
