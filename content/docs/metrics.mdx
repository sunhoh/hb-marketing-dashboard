매체에서 받는 건 **소진액·노출·클릭·전환** 네 가지 원본 값뿐이에요. 나머지는 모두 원본을 합친 뒤 공통 함수(`lib/metrics.ts`)로 계산해요.

<Callout type="warn" title="평균의 평균을 내지 않아요">
  CTR·CPC·CPM 은 캠페인별 비율을 평균 내지 않고, **원본 값을 먼저 다 더한 뒤** 한 번 나눠요.
  그래서 캠페인 CTR 을 평균 낸 값과 합계 줄의 CTR 이 다를 수 있어요.
</Callout>

## 원본 지표

| 지표 | 뜻 | 매체별 기준 |
|---|---|---|
| 소진액 | 광고비(원) | 네이버: 총비용(salesAmt), 메타: 지출 금액(spend) |
| 노출 | 광고가 보인 횟수 | |
| 클릭 | 광고를 누른 횟수 | 메타는 **링크 클릭**(inline_link_clicks). 좋아요·프로필 클릭은 빼고 네이버와 기준을 맞췄어요 |
| 매체 전환 | 매체가 센 전환 | 아래 표 참고 |

## 파생 지표

| 지표 | 계산 | 좋은 방향 |
|---|---|---|
| CTR | 클릭 ÷ 노출 × 100 | 높을수록 |
| CPC | 소진액 ÷ 클릭 | 낮을수록 |
| CPM | 소진액 ÷ 노출 × 1,000 | 낮을수록 |
| 도착률 | 랜딩 방문 ÷ 링크 클릭 × 100 | 높을수록 |
| 방문당 비용 | 소진액 ÷ 랜딩 방문 | 낮을수록 |
| 홈페이지 전환율 | 홈페이지 전환 ÷ 세션 × 100 | 높을수록 |
| 구글 평균 순위 | 순위 × 노출의 합 ÷ 노출 | 낮을수록(1위가 가장 좋음) |
| 증감률 | (이번 기간 − 비교 기간) ÷ 비교 기간 × 100 | 지표에 따라 |

도착률과 방문당 비용은 [랜딩 방문과 UTM](/docs/landing-utm) 에서 자세히 설명해요.

## 매체 전환

'매체 전환'은 **매체가 스스로 센 전환**이에요. 실제 예약·내원과는 달라요.

- **메타** = 메시지 대화 시작(WhatsApp·메신저·인스타 DM) + 리드(인스턴트 양식 제출).
  LINE·카카오·홈페이지로 보내는 광고는 메타가 전환을 알 수 없어서 **0으로 보여요**.
- **네이버** = 광고주센터 전환추적에 잡힌 전환 수.

## 표시 규칙

- **분모가 0이면 `—`** 를 보여 줘요. 예: 노출이 0이면 CTR 은 `—`.
- **소진액이 0이면 CPC·CPM 도 `—`** 예요. 네이버 브랜드검색처럼 계약형이라 일별 비용이 0인 경우에 ₩0으로 보이지 않게 했어요.
- 금액은 `₩` 와 천 단위 콤마(₩1,234,567). 좁은 칸과 차트 축은 `₩350만`, `₩1.2억` 처럼 줄여요.
- 비율은 소수점 둘째 자리까지(2.35%).

## 색

| 표시 | 뜻 |
|---|---|
| <span style={{ color: "var(--tone-up)" }}>▲ 빨강</span> | 비교 기간보다 **올랐다** |
| <span style={{ color: "var(--tone-down)" }}>▼ 파랑</span> | 비교 기간보다 **내렸다** |
| <span style={{ background: "var(--warn-bg)", color: "var(--warn-fg)", padding: "0 4px", borderRadius: 4 }}>주황</span> | 평소보다 **나쁘다** |

증감 색은 증권 앱처럼 **방향만** 나타내요. CPC 가 올라도 빨강, 내려도 파랑이에요. 좋고 나쁨은 주황 칸과 OFF 후보 배지로만 표시해요.
